常见问题

简短回答

每条回答下面都有链接，指向完整讲解这个话题的文章。

一定要用麦克风吗，可以关掉吗？

不是必须的。开着麦克风，应用能听见你的呼吸、测出你跟节奏跟得有多准，并给你打分。关掉之后，圆圈、节奏、震动、连续天数、里程碑和计划都照常工作——只是不再算分。你可以在练习开始时点“不用麦克风继续”，也可以在设置里彻底关掉。

详细：呼吸听不到的时候 →

会录音吗？

不会。麦克风只在练习期间工作，并且只从中算出当下的声音强度——不会有音频文件写到磁盘上。唯一的例外是你另外授权的声音样本分享。如果你没有打开它，任何一次练习都不会录音。

详细：管理你的数据 →

我的呼吸听不到，该怎么办？

按顺序来：把设备拿在离嘴 20-30 厘米的地方、别挡住麦克风、找个安静的地方，练习开头显示“正在测量房间”时别动。别为了让声音大一点而用力呼吸——那不会修好测量，只会毁掉它。

详细：呼吸听不到的时候 →

分数是怎么算的？

把几项各自独立的测量合在一起：节奏吻合、听到的呼气、呼气长度、吸气、呼吸音量、呼气是否平稳，以及你有没有练完。它们的权重并不相同；占比最大的是节奏吻合。

详细：一次练习的分数怎么算 →

练习中出现的那几行小字是什么？

是出现在圆圈下面、几秒后淡去的提示：“稍微晚了一点”“你的呼吸不太听得清”“屏息时漏气了”之类。它们指的都是练习结束前你还来得及调整的事，踩准的循环也会得到一句表扬。它们不会频繁出现：第一个循环和最后几秒不出现，两条之间至少隔十秒，同一句话最多出现两次。它们看的阈值和报告背后的测量是同一个，所以永远不会互相矛盾。

详细：练习界面上都有什么 →

报告里的那张图显示的是什么？

在“进阶”界面下，有一条线显示整场练习测到的声音强度：房间的底噪、一次呼吸要越过才算数的阈值，以及你呼吸的波峰。后面的色带标出呼气和吸气的时间窗，所以你能用眼睛看出自己在哪个循环晚了。这条线不是声音——应用不保存任何音频文件，只有它测到的强度，而且它们留在你的设备上。

我分数很低，是不是做错了？

分数低并不意味着你呼吸错了。分数只测量你跟屏幕上的节奏跟得有多准——不测量这次呼吸对你有没有好处。而且测量依赖麦克风：坐得离设备远、房间吵，都可能让一次很好的练习看起来分数很低。点“详细报告”，就能看到是哪一项掉了下来、要调整什么。

详细：读懂练习报告 →

一次练习应该练几分钟？

哪怕两分钟也有用。时长滑块上亮起的那一段，是为你建议的区间：它会随你的经验、最近几次练习、一天中的时间和连续天数移动。按任何标准，一次练完的短练习都胜过一次半途而废的长练习。

详细：选呼吸法和时长 →

为什么有些呼吸法是锁着的，怎么解锁？

路线是从易到难：先从没有屏息的呼吸法开始，再到带屏息的，然后是进阶的。点一张锁着的卡片，它会告诉你需要什么，以及最短的路。如果你在开场问题里把经验水平填得很高，大部分锁一开始就是开的。

详细：解锁呼吸法 →

什么时候该做哪一种？

睡前用 4-7-8 或长呼气，工作间隙用箱式或三角呼吸，突然紧张时用生理性叹息，觉得发懵时用提神呼吸或右鼻孔呼吸。要是拿不定主意，就用列表最上面那条建议：它是根据你的目标、一天中的时间和最近几次练习选出来的。

详细：什么时候做什么 →

连续天数怎么算，断了一天会怎样？

连续天数数的是你连着多少天练了。断一天会清零，但你最长的纪录会保留下来，第二天就开始新的一串。一天里练好几次不会让它涨得更快：它数的是天，不是次数。

详细：连续天数、里程碑和日历 →

我要休息一段时间——连续天数保得住吗？

保得住。打开“设置 → 通知选项 → 假期模式”：通知会安静到你设定的日期，连续天数也会被保住。有一点要注意：假期模式会结束正在进行的计划，因为计划是一直在数天数的。切换到假期模式之前，应用会就这一点问你。

详细：连续天数、里程碑和日历 →

计划是什么，和连续天数有什么不同？

连续天数问的是“你今天做了点什么吗”；计划问的是“同样的呼吸法、同样的时长，你练了多少天”。研究里测到的那些效果来自后者。第一个计划是二十八天，每天五分钟——那正是这个计划所依据的研究里用的时长。

详细：建立一个计划并坚持下去 →

计划里断了一天怎么办？

断一天不会让计划失败。如果开始连着断，应用会提醒你；断到一定天数，计划就结束了。结束的计划不会被删掉：它会进入你的历史，你走到了哪一步会留在那里。

详细：建立一个计划并坚持下去 →

我的数据在哪里，会出现在我另一台设备上吗？

你的练习记录保存在你的设备上；如果 iCloud 是开着的，它会在你自己的 iCloud 账户里同步——所以你在另一台设备上登录时，记录就在那里。我们作为开发者对那块区域没有访问权限。你的个人资料和设置也会同步。

详细：管理你的数据 →

需要联网吗？

不需要。练习、测量、评分、计划和通知全都在设备上运行。只有 iCloud 同步，以及你自己打开的匿名分享，才会用到网络。

有内购或订阅吗？

没有。应用里没有任何东西出售，也没有订阅。

为什么要问年龄和健康情况？

有些呼吸法涉及长时间屏息和快速呼吸。如果你有健康备注，那些呼吸法会掉到列表最下面，旁边出现提示。如果你的年龄落在某些区间，建议的时长和轮数上限也会变。这两个问题都是可选的，而且都不会离开你的设备——它们从不发送。

详细：你的建议取决于什么 →

练习中觉得头晕该怎么办？

停下来，回到平常的呼吸。头晕、发麻或视线发暗不是该硬撑过去的症状。如果你正在做带长屏息的呼吸法，可以跳过屏息，或者把它缩短。

有哮喘、心脏问题或怀孕时可以做哪些？

如果你在开场问题里标了这些，应用会把风险较高的呼吸法移到最后、显示提示，并调低一些上限。即便如此，这不是医学评估：在这些情况下，开始任何练习前请先咨询医生。

通知太多了，怎么减少？

在“设置 → 通知选项”里，每一类都可以单独关掉。你可以给一天的通知数量设上限、设定不想被打扰的时段，或者全部关掉。没有通知，应用照样完整地工作。

详细：提醒与通知 →

界面太满了，或者太空了

在“设置 → 界面”里可以在三个层级之间切换：简洁、标准、进阶。没有任何功能被关掉；变的只是你看到多少信息。

怎么添加小组件？

在手机（或平板）主屏幕的空白处长按，点左上角的加号，从列表里选 Soluklan。锁屏的话，长按时钟进入“自定”。点小组件会直接带你去选呼吸法。

详细：小组件与实时活动 →

练习结束时的评分问题是什么，会发送什么？

如果你打开了匿名分享，它会偶尔出现：十分制的评分，后面再跟一个问题。两者都可以跳过；如果你给了分数、没写字就离开，底部的按钮会写着“只发送分数”，所以分数不会被丢掉。除了分数，你写的文字也会一起发送，而且我们会读，所以别在框里写能认出你的信息。你的姓名、邮箱和健康回答在这里同样不会发送。

详细：我们拿分享的数据做什么 →

怎么删除我的全部数据？

在个人页最下面有一个删除我的数据按钮。确认之后，你的练习记录、连续天数、成就、心率记录和开场回答都会被删除。这个操作无法撤销。如果你也希望删除匿名分享出去的记录，写信到支持邮箱就够了。
