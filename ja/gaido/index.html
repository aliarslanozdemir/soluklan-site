よくある質問

短い答え

どの答えの下にも、そのテーマをくわしく説明する記事へのリンクがあります。

マイクは必要ですか？オフにできますか？

必須ではありません。マイクがオンのときは、アプリが呼吸を聞き取り、リズムにどれだけ合っているかを測ってスコアをつけます。オフでも、円、リズム、振動、連続記録、マイルストーン、プログラムはそのまま使えます。スコアが計算されないだけです。セッションの開始時に「マイクなしで続ける」を選ぶか、設定から完全にオフにできます。

詳しくは：呼吸が聞こえないとき →

音声は録音されますか？

いいえ。マイクが動くのはセッション中だけで、音から計算するのはその瞬間の音量だけです。音声ファイルがディスクに書き込まれることはありません。唯一の例外は、別途許可した場合の音声サンプルの共有です。その許可をオンにしていなければ、どのセッションでも音声は録音されません。

詳しくは：データの管理 →

呼吸が聞き取られません。どうすればいいですか？

順番に試してください。デバイスを口から20〜30センチの距離に持つ、マイクをふさがない、静かな場所を選ぶ、そしてセッションの最初に「周囲の音を測定中…」と表示されている間は動かない。呼吸を無理に大きな音にしようとしないでください。測定がよくなるどころか、かえって乱れます。

詳しくは：呼吸が聞こえないとき →

スコアはどのように計算されますか？

それぞれ独立した測定値をまとめて計算します。リズムへの一致、聞き取れた吐く息、吐く息の長さ、吸う息、呼吸の音、吐く息のなめらかさ、そしてセッションを最後まで行ったかどうかです。重みはすべて同じではなく、いちばん大きな割合を占めるのはリズムへの一致です。

詳しくは：セッションのスコアのつけ方 →

セッション中に出る短いメッセージは何ですか？

円の下に現れて数秒で消えるメモです。「少し遅めでした」「息が聞き取りにくいです」「息止めの間に息がもれました」などがあります。セッションが終わる前に直せることを伝えるもので、うまくいったサイクルではほめ言葉も出ます。集中を妨げないよう、出る頻度は控えめです。

詳しくは：セッション画面にあるもの →

レポートのグラフは何を表していますか？

アドバンス表示では、セッション中に測った音量を示す線が表示されます。部屋の周囲の音、吐く息として数えられるために超える必要があるしきい値、そして呼吸のピークです。背景の帯は吐く息と吸う息のタイミングを示していて、どのサイクルで遅れたかがひと目でわかります。この線は録音ではなく、測った音量だけです。それもデバイスの中に残ります。

詳しくは：セッションレポートの読み方 →

すべて見る
スコアが低かったのですが、やり方が間違っていますか？

スコアが低いからといって、呼吸の仕方が間違っているわけではありません。スコアが測るのは画面のペースにどれだけ合っているかだけで、その呼吸が自分に合っているかどうかではありません。しかも測定はマイクに頼っています。デバイスから離れていたり周りがうるさかったりすると、しっかりできたセッションでもスコアが低く出ることがあります。レポートの「詳しく見る」を開くと、どの測定値が下がったか、何を直せばいいかがわかります。

詳しくは：セッションレポートの読み方 →

セッションは何分行えばいいですか？

2分でも十分です。時間スライダーの光っている帯が、おすすめの範囲です。経験、最近のセッション、時間帯、連続記録に応じて動きます。最後までやり終えた短いセッションは、途中でやめた長いセッションよりどの点でもすぐれています。

詳しくは：呼吸法と長さの選び方 →

呼吸法がロックされているのはなぜですか？どうすれば解除できますか？

やさしいものから難しいものへと順に進みます。息止めのない呼吸法から始めて、息止めのあるもの、そして上級の呼吸法へ。ロックされたカードをタップすると、解除に必要なことといちばんの近道が表示されます。はじめのチェックで経験を高めに選んだ場合は、ほとんどのロックが最初から解除されています。

詳しくは：ロックされた呼吸法を解除する →

どの呼吸法をいつ行えばいいですか？

寝る前は4-7-8呼吸法かロング呼気、仕事の合間はボックス呼吸かトライアングル呼吸、急に緊張したときは生理的ため息、ぼんやりするときはエナジー呼吸か右鼻呼吸。迷ったら、リストのいちばん上のおすすめを選んでください。目的、時間帯、最近のセッションをもとに選ばれています。

詳しくは：どの呼吸法をいつ行うか →

試験やプレゼンの前には、どの呼吸エクササイズをすればいいですか？

10〜15分前に2〜3分とりましょう。筆記試験の前ならボックス呼吸、プレゼンや面接試験のように話す場面の前なら、吐く息の長いリズムが向いています。ロング呼気かコヒーレント呼吸です。順番を待つ間は、生理的ため息を2〜3回か、長く吐く呼吸を数回で十分です。当日に新しい呼吸法を試すのはやめておきましょう。

詳しくは：どの呼吸法をいつ行うか →

デスクで呼吸の休憩をとるにはどうすればいいですか？

席を立つ必要はありません。背すじを伸ばして座り、画面から目を離し、肩の力を抜いて、2〜3分ボックス呼吸かトライアングル呼吸をします。休憩を忘れがちなら、一日の決まった時間にリマインダーを設定できます。

詳しくは：どの呼吸法をいつ行うか →

横隔膜呼吸はどうやるのですか？アプリにありますか？

片手を胸に、もう片方の手をおなかに置き、鼻からゆっくり吸います。おなかの手が持ち上がり、胸の手はほとんど動かないようにします。それから吸う息より少し長く吐きます。アプリに横隔膜呼吸だけのセッションはありません。これは一つの呼吸法ではなく、ゆっくりした呼吸法すべての土台だからです。練習するなら、コヒーレント呼吸や深くゆっくり呼吸がおすすめです。

詳しくは：横隔膜呼吸とは →

子どもも呼吸エクササイズができますか？

はい。大人と一緒に、短く、遊びのように。1〜2分、息止めのないゆっくりしたリズムで行います。はじめのチェックで年齢に「13歳未満」を選ぶと、おすすめの時間が短くなり、速い呼吸や長い息止めのある呼吸法には注意も表示されます。

詳しくは：呼吸エクササイズのやり方 →

連続記録はどう数えられますか？1日休んだらどうなりますか？

連続記録は、何日続けてセッションを行ったかを数えます。1日休むと0に戻りますが、最長の連続記録は残り、新しい連続記録は翌日から始まります。1日に何回セッションをしても連続記録は速く伸びません。数えるのは日数で、セッションの回数ではないからです。

詳しくは：連続記録、マイルストーン、カレンダー →

しばらく休む予定です。連続記録は守られますか？

はい。設定 → 通知オプション → 休暇モードをオンにして、3日、1週間、2週間のいずれかを選びます。その間は通知が止まり、連続記録も守られます。一つ注意があります。休暇モードにすると進行中のプログラムは終了します。プログラムは日数を数え続けるためです。アプリは休暇モードに入る前に確認します。

詳しくは：連続記録、マイルストーン、カレンダー →

プログラムとは何ですか？連続記録とどう違いますか？

連続記録が問うのは「今日なにかしたか」、プログラムが問うのは「同じ呼吸法を同じ時間で何日続けているか」です。測定される効果は後者から生まれます。最初のプログラムは28日間、1日5分。この長さは、プログラムのもとになった研究で行われた期間です。

詳しくは：プログラムの設定と続け方 →

プログラムの途中で日を空けたらどうなりますか？

1日空けてもプログラムは終わりません。続けて休むようになるとアプリが知らせ、一定の日数を超えるとプログラムは終了します。終了したプログラムは消えません。履歴に移り、どこまで進んだかがそこに残ります。

詳しくは：プログラムの設定と続け方 →

データはどこに保存されますか？ほかのデバイスでも見られますか？

セッション履歴はデバイスに保存され、iCloudがオンなら自分のiCloudアカウントで同期されます。つまり、ほかのデバイスでも履歴が見られます。この領域に開発者はアクセスできません。設定とはじめのチェックの回答も、同じアカウントで同期されます。

詳しくは：データの管理 →

インターネット接続は必要ですか？

いいえ。セッション、測定、スコア、プログラム、通知はすべてデバイスの中で動きます。インターネットを使うのは、iCloudの同期と、オンにした場合の匿名共有だけです。

アプリ内課金やサブスクリプションはありますか？

ありません。アプリ内で販売しているものも、サブスクリプションもありません。

年齢や健康について質問するのはなぜですか？

呼吸法の中には、長い息止めや速い呼吸を含むものがあります。健康上の注意がある場合、それらの呼吸法はリストのいちばん下に移り、横に注意が表示されます。年齢が特定の範囲にある場合は、おすすめの時間やサイクル数の上限が変わります。どちらの回答も任意で、どちらもデバイスの外に出ることはなく、送信されることもありません。

詳しくは：おすすめは何で決まるか →

セッション中にめまいがしたらどうすればいいですか？

止めて、ふだんの呼吸に戻ってください。めまい、しびれ、目の前が暗くなる感じは、「続ければおさまる」と考えてよい症状ではありません。長い息止めのある呼吸法なら、息止めをスキップするか、短くすることができます。

ぜんそく、心臓の持病、妊娠中の場合、どの呼吸法ができますか？

はじめのチェックでこれらを選ぶと、アプリはリスクのある呼吸法をいちばん下に移して注意を表示し、一部の上限を下げます。ただし、これは医学的な判断ではありません。こうした場合は、エクササイズを始める前に医師に相談してください。

通知が多すぎます。減らすにはどうすればいいですか？

設定 → 通知オプションで、種類ごとに個別にオフにできます。1日に届く通知の上限を決めたり、通知を受けたくない時間帯を指定したり、すべてまとめてオフにしたりもできます。アプリは通知なしでも問題なく使えます。

詳しくは：リマインダーと通知 →

アプリがごちゃごちゃしている、または物足りないと感じます

設定 → 表示で、シンプル、スタンダード、アドバンスの三つのレベルを切り替えられます。オフになる機能はなく、表示される情報の量が変わるだけです。

詳しくは：表示をシンプルにする、または広げる →

ウィジェットはどうやって追加しますか？

スマートフォン（またはタブレット）のホーム画面の何もないところを長押しし、左上のプラスをタップして、リストからSoluklanを選びます。ロック画面の場合は、時計を長押しして「カスタマイズ」に進みます。ウィジェットをタップすると、呼吸法の選択画面が直接開きます。

詳しくは：ウィジェットとライブアクティビティ →

セッションの最後に出る評価の質問は何ですか？何が送信されますか？

匿名共有をオンにしている場合に、ときどき表示されます。10点満点の評価と、そのあとにもう一つだけ質問があります。どちらもスキップでき、評価だけ入れて何も書かずに送ることもできます。評価と一緒に書いた文章も送信され、それは私たちが読みます。ですから、入力欄には個人が特定できることを書かないでください。名前、メールアドレス、健康についての回答は、ここでも送信されません。

詳しくは：共有されたデータをどう扱っているか →

すべてのデータを削除するにはどうすればいいですか？

プロフィールページの下にデータを削除ボタンがあります。確認すると、セッション履歴、連続記録、実績、心拍数の記録、はじめのチェックの回答が削除されます。元に戻すことはできません。これまでに共有した匿名の記録も削除したい場合は、サポートのアドレスにご連絡ください。

詳しくは：データの管理 →

クイックスタートとは何ですか？どう使いますか？

選択画面を通らずに、そのときのおすすめの呼吸法と時間でセッションを始めます。進行中のプログラムがあれば、今日のセッションで始まります。ホーム画面の「はじめる」を1秒長押しするか、アプリのアイコンを長押しして「クイックスタート」を選ぶか、Siriに「Soluklanで呼吸のセッションを開始」と話しかけます。毎回この方法で始めたい場合は、設定 → クイックスタートでオンにしてください。

詳しくは：呼吸法と長さの選び方 →

セッションが記録されなかったのはなぜですか？

予定したサイクルの一定の割合を行うと、セッションが記録されます。必要な割合は、一時停止メニューのリングにうっすらと色がついている部分です。そこに届く前に終了すると、セッションは保存されません。

詳しくは：連続記録、マイルストーン、カレンダー →

Apple Watchでセッションを行うにはどうすればいいですか？

Apple Watch用アプリはiPhoneのアプリと一緒に提供されていて、iPhoneのWatchアプリからインストールします。Apple Watchで「はじめる」をタップします。おすすめの呼吸法と時間が選ばれた状態で始まり、下のカプセルから変更することもできます。リズムは手首への振動で伝わり、腕を下ろしてもセッションは続きます。

詳しくは：Apple WatchでSoluklan →

Apple Watchに心拍数が表示されません。どうすればいいですか？

心拍数を表示するには、Apple Watchにヘルスケアへのアクセスを許可する必要があります。心拍数を読み取り、セッションをワークアウトとして開始するためです。許可はApple WatchでSoluklanを開いたときに求められます。許可をオフにした場合は、iPhoneのヘルスケア → プロフィール → プライバシー → App → Soluklanで、心拍数とワークアウトをオンにしてください。ヘルスケアにデータは書き込みません。

詳しくは：Apple WatchでSoluklan →

iPhoneとApple Watchを一緒に使うにはどうすればいいですか？

呼吸法の選択画面で「Apple Watchと一緒のセッション」をオンにして、「はじめる」をタップします。短い準備ページが表示され、その間にApple Watchが起動します。「準備OK」をタップすると、両方が同時に始まります。呼吸はiPhoneで、心拍数はApple Watchで測り、セッションはiPhoneが進めます。

詳しくは：一緒にセッション →

Apple Watchが一緒のセッションにつながりません。どうすればいいですか？

Apple Watchを腕に着けてロックを解除し、iPhoneのBluetoothをオンにしてください。Apple WatchでSoluklanを一度手動で開き、ヘルスケアへのアクセスを許可します。つながらなくてもセッションはiPhoneで始まり、あとからApple Watchがつながればセッションに加わります。

詳しくは：Apple Watchが接続されないとき →

Apple Watchでセッションを一時停止したり、再開したりするには？

左上のボタンをタップすると、一時停止メニューが開きます。左上の×でメニューを閉じると、セッションは今のサイクルの最初から、3・2・1のカウントのあとに再開します。メニューから、サイクルやセッションを最初からやり直したり、セッションを終了したりできます。

詳しくは：Apple WatchでSoluklan →

クイックスタートの「Apple Watchでは常に使う」がグレー表示になっているのはなぜですか？

Apple WatchはiPhoneとペアリングされていますが、SoluklanがApple Watchにインストールされていません。iPhoneのWatchアプリからSoluklanをApple Watchにもインストールすると、スイッチがオンにできるようになります。

詳しくは：Apple WatchでSoluklan →

自分で作ったマイルストーンを変更するには？

連続記録の画面にあるマイルストーンのカードで、自分で作ったマイルストーンは別のリストにまとまっています。どれかをタップすると、名前、日数、画像、色を変更したり、削除したりできます。削除しても「自分の道」の実績は獲得したまま残ります。

詳しくは：連続記録、マイルストーン、カレンダー →
